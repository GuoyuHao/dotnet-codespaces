## 📋 Documentation Standards

All documentation in this project follows these standards:

- **Markdown Format**: All docs use GitHub-flavored Markdown (.md)
- **Structure**: Clear hierarchy with headers and subheaders
- **Code Examples**: Syntax-highlighted code blocks where appropriate
- **Links**: Cross-references between related documentation
- **Images**: Screenshots and diagrams where helpful
- **Keep Current**: Documentation updated with code changes
